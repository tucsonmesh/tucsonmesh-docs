# Troubleshooting Guide

This guide is designed to help Tucson Mesh users and admin members troubleshoot connectivity issues.


!!! info "This guide is a work in progress!" 

    This guide doesn't provide troubleshooting steps to diagnose every possible problem. We hope to update it as we identify frequent issues users have.

## Getting help in real time

This guide is designed for users to try to step through themselves. However, if you want real-time support, the best way is through the [`#user-support` channel on our Slack](https://tucsonmesh.slack.com/archives/C03P19L1WBF). This is the best way to ask for help because it allows other users and volunteers to collaborate to help you figure out your issue. This method will also likely get the fastest response.

You can also email <a href="mailto:support@tucsonmesh.net">support@tucsonmesh.net</a> with questins or issues.
